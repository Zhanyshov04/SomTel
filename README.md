# SOMTEL Money Transfer Telegram Bot

SOMTEL is a Telegram bot project developed to help users calculate money transfer commissions between Kyrgyzstan and Turkey.

Users can:
- Select the sending country
- Enter transfer amounts
- Calculate commission fees automatically
- View live exchange rates
- Use the bot in Kyrgyz, Turkish, and English

The project was developed with Python using Telegram Bot technologies and asynchronous programming.

---

## Technologies Used
- Python
- Aiogram
- Asyncio
- Aiohttp
- Telegram Bot API
---

## Features
- Multi-language support
- Commission fee calculator
- Live exchange rates
- Interactive Telegram menu system
- Real-time calculations

---

## Installation
```bash
pip install aiogram aiohttp
```
